XBOARD / DESKTOP

桌面仪表盘

连接你的 Xboard 管理面板，仅读取仪表盘统计。

01

面板连接

后台授权值会通过 Windows 安全存储加密保存。

如何找到后台安全路径和授权值？
  1. 从后台网址复制域名作为面板地址；地址中域名后的路径（不含 / 和 #）就是安全路径。
  2. 登录后台后按 F12 →「应用程序」→「本地存储」→ 当前域名。
  3. 找到 XBOARD_ACCESS_TOKEN，打开其 JSON 内容，复制 value 的完整值（包含 Bearer ）。不要把授权值发给任何人。
修改连接信息后，点击此按钮开始连接。
